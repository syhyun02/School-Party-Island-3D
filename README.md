# 스쿨 파티 아일랜드 3D
실행 가능한 첫 개발 프리뷰. React + TypeScript + R3F/Three.js + Node.js + Socket.IO.

## 실행 (Mac M4 / Linux)
Node.js 22.12 이상을 설치한 뒤:
```sh
npm ci
npm run admin:setup
npm run dev
```
Vite가 표시하는 주소로 접속하세요. 같은 네트워크의 스마트폰에서는 개발 PC의 IP와 Vite 포트를 사용합니다.
관리자 비밀번호는 생성된 .env 파일을 로컬 편집기로 열어 확인하세요. .env가 이미 있다면 ADMIN_PASSWORD를 12자 이상으로 직접 설정합니다. 비밀번호를 변경한 뒤 서버를 다시 시작해야 합니다.
각 브라우저 프로필에서 닉네임과 학급, 캐릭터를 선택하면 최대 4인 방으로 자동 배정됩니다. 현재 접속 중인 첫 참가자가 게임을 선택합니다. 혼자서도 연습 가능합니다.
로비에서 미니게임 이름을 누르면 서버의 3초 준비 카운트다운 후 해당 게임을 60초 동안 플레이합니다. 결과 화면에서 선택 화면으로 돌아갈 수 있습니다. 연습 보상은 누적하지 않습니다.
보드 모드는 45초 보드 단계(진행 중인 퀴즈가 있으면 응답 종료까지 연장) → 3초 준비 → 60초 미니게임 → 10초 결과 화면 순서로 총 5라운드입니다. 시작 시 6종을 섞어 중복 없이 5종을 선택합니다.
주사위는 한 번만 굴릴 수 있고 미입력 시 서버가 대신 굴립니다.
이동은 가상 조이스틱 또는 방향키/WASD, 동작은 화면 버튼 또는 스페이스입니다. 점프 1초, 대시/돌진 1.6초, 부스터 3초의 재사용 대기시간이 있습니다.
재접속 토큰은 localStorage에 보관됩니다. 서버 재시작 시 방 데이터는 초기화됩니다.

## 검증 및 배포
```sh
npm test
npm run build
npm start
```
프로덕션 서버는 dist 정적 파일과 Socket.IO를 같은 포트에서 제공합니다.
Render Node Web Service: Build = npm ci --include=dev && npm run build, Start = npm start.
PORT는 플랫폼에서 주입하며 기본값은 3001입니다. /health에서 상태를 확인합니다.
현재 단일 프로세스 메모리 상태이므로 인스턴스는 1개로 실행해야 합니다.

## 현재 구현
- 네 지역의 입체 섬, 풍차/등대/배/유적/도시, 다리, 물결 셰이더, 실시간 그림자
- 표정과 팔다리가 있는 오리지널 동물 캐릭터 4종, 칸별 걷기 이동, 이동 추적 카메라와 32칸 보드
- 4색 캐릭터, 이동 보간, 코인/별, 서버 난수와 중복 주사위 차단
- 최대 4인 자동 배정, 서로 다른 학급 우선, 재접속
- 서버 판정 미니게임 6종, 60초 제한, 5라운드와 보상
- 서버 이동/충돌/생존/완주/사진 점수 판정, 입력 정규화와 350ms 입력 만료
- 동률 공동 순위, 소인원 순위 보정(순위 구간을 4인 보상표로 반올림 매핑: 3인은 100/50/30점), 마지막 라운드 기여 점수 1.5배
- 모바일 가로 화면, 터치 점프, 저해상도 설정

## 아직 구현되지 않은 항목
행사용 완성본이 아닙니다. 참가 코드, 학생 신원 기반 중복 방지, 전체 방 공통 타이머, PostgreSQL 영속화, 확정 명단 기반 학급 평균, Rapier 물리, 부하 테스트가 남아 있습니다.
관리자 비밀번호가 설정되면 본 경기는 교사만 시작하며, 방장은 미니게임 연습을 시작할 수 있습니다. 35분 행사 진행과 200~300명 성능은 검증되지 않았습니다.
실제 스마트폰의 GPU 성능/FPS 및 300명 부하는 별도 검증이 필요합니다.


## 미니게임 규칙
| 게임 | 플레이 및 순위 |
|---|---|
| 컬러 아일랜드 | 5×5 컬러 발판. 6초 안내 후 1.5초 붕괴, 반복. 안전한 색으로 이동. 점프 중 착지를 늦출 수 있지만 안전하지 않은 칸에 내려오면 탈락. 생존 여부/시간 순. |
| 운석을 피해라 | 1.6초 전 착탄 위치 경고, 반경 1.25 충돌 판정, 체력 3. 경고 빈도가 점점 증가. 남은 체력, 생존 시간 순. |
| 등대 점프 | 회전 속도가 증가하는 장애물, 점프 높이와 각도로 충돌 판정. 체력/생존 시간 순. |
| 에코 카트 | 원형 트랙 자동 가속, 좌우로 차선 변경, 아래 방향으로 브레이크. 잔디 이탈 감속. 중앙 차선의 보급 지점 통과 시 부스터 획득(최대 3개). 서버가 전진 거리를 적분해 2바퀴 검증. 완주 시간, 미완주 시 거리 순. |
| 포토존 | 10초마다 총 6회 촬영, 중심 거리 비례 0~100점. 캐릭터 간 밀기와 대시. 합계 순. |
| 로봇 범퍼 | 풍선 3개, 방향을 향한 돌진 접촉으로 피해. 피격 후 1초 무적. 남은 풍선 우선, 공격 성공 횟수 다음. |

현재 물리는 단순화한 서버 원/거리/각도 판정입니다. Rapier와 정교한 카트 물리는 아직 도입하지 않았습니다.
연습방에서도 연결이 끊기면 입력은 멈추며 경기는 계속됩니다. 재접속 시 현재 상태를 복원합니다.
미니게임 시뮬레이션과 미니게임 중 상태 전송은 20Hz, 그 외 단계의 상태 전송은 4Hz(이벤트 발생 시 즉시)입니다. 클라이언트는 스냅샷 사이를 매 프레임 보간하고, 자신의 캐릭터는 입력 즉시 로컬에서 먼저 움직인 뒤 서버 판정 위치로 부드럽게 보정하며(판정은 계속 서버 기준), 움직이지 않는 배경과 캐릭터 몸체는 하나의 메시로 합쳐 그립니다. 서버 지연 시 충돌 단계를 건너뛰지 않아 실시간 종료가 늦어질 수 있습니다.

## 자동 테스트
- `npm test`: 보드 및 6종 게임 규칙, 유효하지 않은 입력, 쿨다운, 보상, 실제 4개 Socket.IO 클라이언트의 호스트 권한/재접속 테스트.
- `npx playwright install chromium` 후 `npm run test:e2e`: 가로 모바일 크기 브라우저에서 6종 입장, 터치/키 입력, 60초 종료와 로비 복귀 확인.
- 시스템 Chromium 사용 시 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`.
- 브라우저 테스트 스크린샷은 `test-results/`에 생성됩니다.


## 교육 퀴즈
- 환경/평화/문화다양성/인권/과학 5개 주제, 4지선다 10문제와 해설 카드.
- 퀴즈 칸에 도착하면 본인에게만 문제를 전달합니다. 정답/해설은 답변 전 클라이언트에 보내지 않습니다. 개발 서버에서도 server 디렉터리의 직접 HTTP 접근을 차단합니다.
- 제한 시간 20초, 유효한 첫 답변만 서버에서 판정합니다. 정답은 개인의 학급 기여 항목에 +10점으로 기록합니다.
- 로비의 퀴즈 연습은 점수를 누적하지 않습니다.
- 보드 시작 25초까지 주사위를 누르지 않으면 자동으로 굴려 퀴즈 응답 시간을 확보합니다.
- 콘텐츠는 `server/content/quizzes.json`에서 수정한 뒤 서버를 재시작합니다. `answer`는 0~3 인덱스입니다. 시작 시 기본 형식/중복 ID를 검사합니다.
- 교사가 일시정지하면 답변을 막고, 재개 시 남은 시간을 보존합니다.

## 교사 로그인과 진행 관리
`/admin`에서 .env의 ADMIN_PASSWORD로 로그인합니다. 학생 참가 토큰으로는 관리자 API를 사용할 수 없습니다.
- 현재 접속 인원, 학급별 참가/접속 현황, 방별 상태와 기여점수
- 모든 대기방 본 경기 시작, 전체 일시정지/재개, 강제 종료와 결과 발표
- 종료된 방을 새 게임 대기로 전환, CSV 다운로드, 로그아웃
- 현재 등록 참가자 평균 표시(행사 확정 명단 기반 최종 정산은 미구현)
- 비밀번호 미설정 시 로그인 API는 503으로 차단됩니다. 기본 공용 비밀번호는 없습니다.
- 서버 메모리에 8시간 세션을 보관하고 HttpOnly/SameSite=Strict 쿠키를 사용합니다. 상태 변경 요청은 CSRF 토큰/Origin을 검증하며, 로그인 실패는 IP별 1분에 5회로 제한합니다.
- 배포 시 플랫폼의 비밀 환경변수에 ADMIN_PASSWORD를 설정하고, HTTPS 및 NODE_ENV=production을 사용하세요. 운영 쿠키는 Secure입니다.
- 서버 재시작 시 교사 세션, 학생 방, 점수는 초기화됩니다. 영속 DB와 개별 교사 계정/비밀번호 복구는 아직 없습니다.
- 재접속 비밀 토큰과 다른 학생에게 보이는 플레이어 ID를 분리했습니다.
- 브라우저의 관리자/퀴즈 테스트는 생성된 로컬 .env 또는 ADMIN_PASSWORD 환경변수를 사용하며 값을 출력하지 않습니다.

## 그래픽 개편 범위
외부 유료 에셋이나 닌텐도 에셋 없이 코드로 만든 3D 모델입니다. 네 지역과 미니게임 배경, 동물형 캐릭터, 표정/팔다리 움직임, 부드러운 지형/건물 모서리, 조명/그림자/물결/추적 카메라를 적용했습니다.
선택한 화질은 브라우저에 저장됩니다. 저사양 모드에서는 그림자와 안티앨리어싱을 끄고 배경 장식 개수 및 렌더링 해상도를 줄입니다.
상용 콘솔 게임 수준의 제작 에셋, 정교한 스켈레탈 애니메이션, 배경음악, 실기기 성능 검증까지 완성된 상태는 아닙니다.


## 캐릭터와 파티 연출
- 입장 화면에서 모모(토끼), 루루(여우), 코코(곰), 보리(다람쥐)를 3D 미리보기와 함께 선택합니다. 대기실에서도 변경할 수 있습니다.
- 서버가 캐릭터 번호를 검증하고 경기 중 변경을 차단합니다. 동일 참가 토큰으로 재접속하면 서버에 저장한 캐릭터를 복원합니다. 보드, 미니게임, 시상대에 동일한 캐릭터가 표시됩니다.
- 같은 캐릭터를 고를 수 있으며, 참가 순서에 따른 바닥 링 색과 목록 번호로 구분합니다. 캐릭터에 따른 능력치 차이는 없습니다.
- 주사위는 서버가 한 번 결정합니다. 0.7초 주사위 애니메이션 뒤 칸당 0.25초로 걷고, 실제 서버 코인/별 증감을 도착 카드로 보여 줍니다. 연출이 점수를 추가하지 않습니다.
- 퀴즈는 도착 시점부터 20초 동안 답변할 수 있습니다. 도착 전 제출, 중복 제출, 만료된 답변은 서버가 거절합니다. 늦은 자동 이동 때문에 퀴즈가 생기면 해당 응답 시간이 끝날 때까지 보드 종료를 늦춥니다.
- 미니게임은 서버에서 3초간 준비 상태를 유지합니다. 이 기간의 이동/액션 입력은 무시하고, 이후 모든 방 참가자가 함께 출발합니다.
- 결과 화면은 실제 순위와 선택 캐릭터를 반영하는 3D 시상대입니다. 동률은 같은 높이와 공동 순위로 표시하며, 축하 조각은 InstancedMesh로 렌더링한 후 숨깁니다.
- 카트의 차체/바퀴/스포일러/헤드라이트/부스터, 로봇의 범퍼, 레이스 출발 게이트/체크무늬/태양광 충전소를 추가했습니다. 경주 판정은 기존 서버 로직을 유지합니다.
- 기본은 무음입니다. 화면의 ‘소리 끔’을 눌러 켜면 Web Audio로 합성한 짧은 주사위·도착 보상·시상 효과음이 재생됩니다. 외부 음원은 사용하지 않습니다. 새 페이지에서는 다시 켜야 합니다.
- 새로운 테스트는 캐릭터 유효성/변경 제한/재접속, 준비 중 선입력 방지, 이동 순서/보드 순환, 도착 전 퀴즈 답변 차단을 검사합니다. 브라우저 테스트는 저사양 설정의 6종 경기와 표준 설정의 캐릭터 선택·퀴즈·교사 진행을 검증합니다.

## Render에 올리기
이 저장소의 main 브랜치를 Render Web Service에 연결하세요. Build Command는 `npm ci --include=dev && npm run build`, Start Command는 `npm start`입니다. 환경변수 `ADMIN_PASSWORD`와 `NODE_ENV=production`을 설정합니다. `render.yaml`을 이용한 Blueprint 배포도 가능합니다. 현재 Blueprint는 유료 Starter 요금제로 선언되어 있으므로, 생성 화면에서 요금제를 확인하세요. `.env` 비밀번호 파일은 저장소에 포함되지 않습니다.
